# Static Web Pages

Static web pages are web pages where the content remains the same unless the developer manually updates it.

## Characteristics

1. **Read-only**
   - No user-driven changes to data.
   - Content is fixed and served as-is.

2. **Simple and Fast**
   - Easy to build and host.
   - Loads quickly because no database interaction is required.

## Examples

- Blogs
- News Sites
- Recipe Websites
- Documentation Pages
- Portfolio Websites
- Landing Pages
- Etc.

## When to Use Static Pages

Use static pages when:

- Content does not change frequently.
- Users do not need to create, update, or delete data.
- Performance and simplicity are priorities.

## Summary

Static web pages display predefined content and do not allow users to modify data. Common examples include blogs, news sites, recipe pages, and other informational websites.

# Dynamic Web Apps

Dynamic web applications allow users to interact with and modify data in real time.

## Characteristics

1. **Read-Write**
   - Users have the ability to create, update, and delete data.
   - Content can change based on user actions.

2. **Highly Interactive**
   - Responds to user input without requiring manual updates from developers.
   - Provides a more engaging user experience.

3. **Displays Your Data**
   - Shows personalized information for each user.
   - Data is often fetched from a database or API.

## Examples

- Bank Websites
- Airbnb
- E-Commerce Websites
- Social Media Platforms
- Task Management Applications
- Online Learning Platforms
- Etc.

## When to Use Dynamic Web Apps

Use dynamic web apps when:

- Users need to interact with data.
- Content changes frequently.
- Personalization is required.
- Data must be stored and retrieved from a database.

## Summary

Dynamic web apps are interactive applications that allow users to read and modify data. They often display personalized information and rely on databases and APIs to provide a rich user experience.
